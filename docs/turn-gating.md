# Native accepted conversation boundary

## Development admission and release qualification

Following the owner's explicit shipping-policy revision, automatic personal
development use can be enabled by the short native workflow in
[enrollment](enrollment.md#short-development-setup-owner-directed-activation-policy).
The opaque profile carries Development or ReleaseQualified provenance. The
100/200/200 corpus below determines only ReleaseQualified status; development
does not fabricate or satisfy it. Both kinds run the same live TurnGate, scope
grants, protected actions, cancellation and exact authority/model checks. The
short measured operating point is explicitly provisional, especially for other
speakers, replay and overlap, and is never described as release qualification.

## Accepted reply failures and listening

Capture, analysis, directedness, qualification and durable-admission failures
remain failures of live voice admission. After the original turn is durably
accepted, task execution, selected-voice lookup and reply playback have separate
failure stages. Report those failures without replaying the turn or resetting a
still-current qualified listener. Before preserving listening after such a
failure, revalidate the original local qualified context and perform one bounded
three-second actor-status read against the paired controller; require the exact
original unrevoked registration and recheck the local context after that await.
Unavailable or changed authority still fails closed through ordinary admission
invalidation. This read does not retry planning, an action or synthesis.

Selected-voice status before normal output has a two-second budget; an unavailable
or mismatched selected/active voice is an explicit output failure, never a silent
successful response. Original planner/speech deadlines and output ownership are
unchanged. A durable answer may remain saved when speech cannot be submitted.

## Native qualification review implementation

The core qualification owner evaluates native observations against the same
frozen operating point used for live admission. Its constructor takes the actual
candidate, explicit native voice-consent revision, actor, adapter bindings and
measured operating points; none is a serialized pass record. Only observations
admitted after that freeze enter its held-out corpus. It records native gate
decisions, not outcomes supplied by the page. Failed or missing captures remain
in denominators and cannot supply required measured coverage.

Review requires at least 100 measured directed-owner attempts with at least 95%
accepted, including observed requests without the assistant name; at least 200
measured non-owner/recorded/playback/overlap attempts with every condition present
and zero accepted; and at least 200 measured owner-conversation attempts with zero
accepted. Any missing adapter prevents positive admission and therefore prevents
qualification. Speaker switches, ambiguous approvals, and capture/control
invalidation remain separate required qualification conditions. Operator labels
describe the condition presented; they cannot assert a gate decision or pass.

Profile and observation overlap/echo evidence bind exact adapter revision,
utterance and native context. A generic clean flag cannot establish those facts.
No-output evidence is limited to native assistant output, with exact retained
output ownership; it does not claim resistance to external replay or synthesis.
During unmeasured output/echo conditions the gate abstains.

Explicit assistant-playback held-outs use a distinct rejection-only observation.
Before capture, native code owns one bounded postmix observation lease and a
fresh output UUID. After the actual measured initial quiet run, the existing
selected-and-active voice preview path speaks the fixed diagnostic request
“Avesra, tell me the time.” The operator explicitly starts this recording; no
background qualification plays audio. The postmix consumer retains only bounded
nonzero speech submission intervals, exact output UUID/epoch and original
monotonic callback timestamps. A negative measurement requires one completed
captured endpoint whose original sample interval overlaps those actual submissions.
Missing, late, overflowing or mismatching evidence stays unknown. This conservative
output-overlap rejection is not acoustic echo cancellation, proof that sound was
heard, or external replay detection. It never produces clean-input evidence.
The original capture deadline is not extended to accommodate synthesis; absent
endpoint/ending quiet remains a missing trial. Cancellation retains the actual
existing output coordinator through cleanup.

See [native utterance ownership](utterance-ownership.md) for the shared endpoint
algorithm and single-consumption PCM lifetime. Component calibration alone still
cannot construct a qualified profile. The native review entry point must also
revalidate owner registration, voice consent and all bound model incarnations.

Collection expires after eight hours. Successful reviewed qualification has a
separate lifetime: a bounded per-user DPAPI report retains the measured counts,
native request identities, operating point, candidate identity, local owner
revision, exact registration, microphone, adapter/incarnation bindings and native
voice-consent revision. It contains no PCM, transcript, embedding or pass Boolean.
The original candidate file is never rewritten. Closing Settings discards only
unreviewed collection; explicit revocation removes the protected report.

Restore reads protected native storage under the actual owner coordinator and
revalidates the candidate, local owner revision, paired device, acknowledged
registration, selected endpoint and live directedness incarnation. The report is
rechecked against its development-measurement or release-corpus invariants before a new session-bound token is
created. Missing or changed evidence leaves readiness closed and never starts a
microphone. Restore honors ordinary mute/pause/deafen/lock controls; it does not
change them. A collection deadline never forces an already reviewed owner to
repeat hundreds of utterances merely because the process restarted.

Runtime tokens last at most twelve hours and require the same fresh restore
checks for renewal. The live directedness digest always includes the observed
engine incarnation. Restore may rebind it only when the original protected report
and fresh controlled-load inspection have equal complete deployment-and-policy
fingerprints and the artifact still matches. That fingerprint covers image,
serving configuration, full artifact roster, policy, helper sources and actual
GPU/runtime identity. Missing fingerprints require the exact original incarnation;
an artifact match alone is insufficient. Stored measurements stay unchanged and
all invariants of the original admission kind are checked again. No report has been qualified from the
generated service recordings used for implementation evidence.

A final transcript and speaker embedding are observations, never an accepted intent or tool authority. The native gate binds each observation to the paired device/session, capture and action epochs, exact microphone endpoint, configured ASR/speaker revisions and utterance ID. Incomplete, stale, repeated, missing or malformed observations abstain. Unknown overlap/echo evidence abstains; absence of a detector is not clean audio. Profile matching uses a normalized representation and a calibrated threshold/margin belonging to that exact qualified profile revision and endpoint. No threshold is supplied by an utterance, model confidence, imported pass flag or UI setting.

At initial capture admission and final analysis, construct current context from the actual acknowledged native session while holding Runtime.local, then the acknowledged-session mutex. The same local lock serializes connection-generation changes and acknowledgment publication. Check exact expected session, capture epoch, connection generation and present capture/readiness/mode conditions inside that critical section; a successful earlier asynchronous check is insufficient. Retain local ownership through final gate analysis so replacement/disconnect cannot interleave between context derivation and admission. These entry points remain closed without a native Development or ReleaseQualified token.

Qualification and enrollment selection remain distinct. The qualified-profile token has private fields and no deserialization. Native review creates it after the short explicit development check or complete release corpus, or by revalidating the corresponding protected report and fresh authority. A saved candidate or selected reference cannot create it. Missing runtime evidence keeps the actual producer in abstention and cannot set enrolled or voice-ready.

No mandatory wake word is imposed. A qualified directed-intent adapter must distinguish a complete assistant-directed request from a context-dependent follow-up, binding its decision to the exact utterance/context and configured adapter revision. A leading assistant name is an optional cue, never sufficient evidence; name-leading commentary to teammates still abstains. Unknown/rejected decisions abstain with or without a name prefix. Whitespace-only final text is malformed. A complete directed request may omit the name. A follow-up additionally requires an opaque single-use invitation derived from a previously accepted conversation turn, an exact context/grant/profile/qualification revision match, a fixed five-second expiry and one of the exact expected responses. A short contextual reply cannot be relabelled a complete request merely to bypass invitation checks. These categories and their positive/negative owner/gaming-conversation evidence must pass the corpus before release qualification. Development admission explicitly carries unvalidated classification limitations.

## Qualification and continuous capture prerequisites

Native launch-only output recording mode suppresses the normal voice producer
before its capture loop starts. This restriction does not rewrite saved settings,
enrollment or readiness, and does not alter explicit setup checks. Ordinary
launches retain the existing qualified admission rules. A silent output diagnostic
must never open an ambient capture window merely because voice is later qualified.

The native qualification owner must bind an exact protected candidate ID/revision, authenticated registered actor and grant revision, stable microphone endpoint, ASR/speaker/signal/overlap/echo/directed-intent adapter and model revisions, and the measured operating points. Its review record identifies the explicit locally observed qualification session, condition breakdown, observation counts, accepted/rejected/abstained outcomes and reviewer authorization. It contains no raw media, imported pass flag, model confidence treated as probability, or default guessed threshold. A02-A05 and the positive/no-wake-word and negative teammate/playback/overlap cases in Plan 001 govern release qualification; the saved six segments alone do not supply those results. Native current checks must revoke the token synchronously on candidate, endpoint, actor/grant, adapter/model or session replacement. A persisted report is evidence to revalidate, not a deserializable authority token.

The normal producer and explicit qualification share native utterance ownership over fresh PCM and immutable Sortformer frames. The measured policy supplies speech, overlap and end-quiet cutoffs. Each capture lease starts suppressed until measured quiet, retains bounded pre-roll and cancels unfinished speech at its hard boundary; EOF never invents an endpoint. Normal endpoint completion closes the microphone, sends bounded remaining captured PCM as the final stream chunk and awaits actual terminal closure before releasing the stream. It can then obtain a fresh lease without changing the user's listening mode. Every utterance repeats current qualified identity/directness checks; silence and rejected/unknown speech remain transient. Shared speech/effects/background-music output and its post-mix stereo reference remain intact. During output the current producer defers capture: no-output evidence requires actual output retirement plus measured quiet, and survives through durable acceptance. It proves neither acoustic echo cancellation nor external replay resistance.

The qualified profile binds an explicit actor UUID, and the consumed conversation retains that actor, device/session/epochs/grant and profile/qualification revisions as opaque native provenance. Signal sufficiency is separate from elapsed capture time and embedding similarity. A qualified signal adapter must supply measured voiced/total/clipped sample counts; the bound operating point controls minimum voiced duration and maximum clipping. Missing signal evidence abstains, including for short follow-ups. No duration or threshold is inferred from a ten-second transport window.

An accepted conversation token has private fields and is consumed once with a fresh context/profile/grant recheck and a short fixed lifetime. It contains the accepted text, not a tool proposal. It may support a spoken answer with no tool effect. The native task dispatcher separately prepares exact typed action payloads, applicable grants and local approvals through the durable controller; it cannot deserialize or promote tool text into an accepted token. No unknown/unaccepted transcript enters UI, durable history, learning or planning.

This token is pre-commit admission. The native effects owner calls the durable conversation transaction with a final current-context, profile and retained no-output check before accepted text reaches planning. The five-second freshness and capture-epoch checks apply before that boundary. After durable task acceptance, mic mute does not silently delete the task: it stays visible/cancellable and follows the durable controller's independent action authorization/cancellation policy.

Current source connects measured endpoint PCM to ASR/speaker analysis, the live reasoner-backed directedness adapter, the qualified gate and durable accepted task dispatch. Actual owner-held-out evidence is still absent. The explicit playback trial supplies conservative native output-overlap rejection evidence, while normal capture defers during output. Acoustic replay/echo detection remains absent; unknown outcomes cannot satisfy negative coverage. Follow-up invitations also require a real accepted conversational invitation source and currently abstain. These are explicit remaining product/evidence gates, not passed M3 criteria.
