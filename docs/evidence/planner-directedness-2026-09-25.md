## Source boundary and review

streaming-preview source. It excludes concurrent C1 utterance/qualification and

`artifacts/planner-directedness-proof-20260925/overlay-files.txt`.

Final archive `source-compile-corrected.tar` SHA256:
`7B531787B0486FC03F8305C7F9CDFD4793D4E069851703EE152DAF010CC74AEC`.

Planner protocol v2 supports a typed launch alias or absolute speaker percentage.
The actual native planner-completion transaction stores the unchanged reply and
links a task only after independent whole-request argument matching, exact
current catalog resolution and existing grants. Unsupported or ambiguous requests
remain waiting for input. Model text cannot supply paths, grants, authority IDs,
approval or a success outcome. Original deadline/caller withdrawal remain owned
through proposal dispatch; successful normal replies transfer their output owner.
Historical v1 stored replies remain readable without admitting v1 wire requests.

Independent review caught and corrected two issues before this snapshot: grants
alone did not independently establish the requested operation/arguments, and the
remaining planner deadline needed to survive proposal preparation/dispatch.
The final source uses the accepted stored request and original monotonic deadline.

The separate directedness route observes transient speech classification before
acceptance. It uses the same real reasoning job/cancellation owner, strict typed
output and original budget. Metadata inspection performs no generation.
Classification binds the exact utterance/context, artifact, container/incarnation
and retained engine identity. It cannot create history, acceptance or permission.
No local classifier accuracy has been inferred from its output shape.
