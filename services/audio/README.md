# Spark audio lanes

The Python 3.12 supervisor serves one separately configured lane per process over a private Unix socket. No LAN audio port, microphone capture, authorization, identity decision, ambient history, or raw-media persistence is implemented here. ASR currently uses bounded whole-utterance transcription; ASR/TTS advertise `streaming: false`. This is an incomplete M3 implementation, not the required streaming voice pipeline.

Each socket directory must belong to the service UID and have mode 0700. The socket is owner-only and checks Linux `SO_PEERCRED`. Run the controller and container with the same UID. Messages are big-endian four-byte length plus UTF-8 JSON, at most 2,000,000 bytes; one request per connection, at most eight connections. One inference/load is admitted per lane with no waiting work queue. Raw input is PCM signed 16-bit little-endian mono 16kHz, base64 encoded, at most 30 seconds. The controller must preserve capture/session freshness and reject unknown speech before durable history or effects.

Protocol v1 has `health`, `load`, `infer`, and `cancel`. Health needs only integer `version: 1` and `operation`. Other requests additionally require canonical nonnil `request_id` and `session_id` UUIDs, positive integer `capture_epoch`, `sequence`, `issued_at_ms`, and `expires_at_ms`. Infer adds a `payload` object; all unknown fields fail closed. Cancel names the active request UUID in the same session with a fresh sequence. Lifetimes are at most 30 seconds, except model load (120 seconds). Admission converts remaining wall-clock lifetime once to a monotonic deadline. Absolute wall-clock drift over one second from the process monotonic anchor rejects admission, including forward jumps; restart after correcting the clock. Sequence/epoch tombstones remain for 125 seconds, longer than any request lifetime plus clock tolerance, with at most 16 retained sessions. Capacity exhaustion rejects explicitly.

Cancellation or expiry terminates the isolated child and releases its model allocations. The next load is cold. A worker still alive after kill/join remains tracked as termination_pending and blocks replacement until observed dead. Every child response is rechecked against generation, session epoch, and monotonic deadline before publication. The process is warm between successful calls, but input/result references are discarded after delivery. Parent and child never log request bodies. Child Python streams and OS output descriptors are redirected to the null device because third-party libraries may include sensitive content in errors. Errors crossing the boundary are fixed categories. A successful load is `loaded_unqualified`, never `ready`; capability and live owner quality remain separate evidence.

Speaker inference returns only a sensitive derived embedding or insufficient-duration result. It neither classifies owner/unknown nor grants permission. Quality, overlap, replay resistance, enrollment and thresholds remain controller work. TTS requires an explicitly selected generated WAV plus adjacent JSON declaring `kind: selected_generated_voice`, exact `base_revision`, and reference `text`. No request can choose a file path. Voice design returns a transient preview; persistence and selection are not implemented. Model changes must invalidate incompatible selected assets.

Run separate environments for `speaker`, `asr`, and `tts` extras; do not combine NeMo and Qwen dependency sets. `Dockerfile.speaker` derives the pinned existing ARM64 CUDA runtime and pins its full inspected package delta. Built image identity and qualification are separate evidence. ASR/TTS extras are candidate versions only and have not been resolved/loaded on Spark. Model directories are mounted read-only, cache is private and distinct from Local Studio. Inference containers use no network and explicit CPU/memory limits. No tests or synthetic audio suites are created under the owner's instruction.

Primary API references: [SpeechBrain audio compatibility](https://speechbrain.readthedocs.io/en/stable/audioloading.html), [SpeechBrain releases](https://pypi.org/project/speechbrain/), [NeMo 3 runtime](https://docs.nvidia.com/nemo/speech/3.0.0/starthere/install.html), [Qwen voice API](https://github.com/QwenLM/Qwen3-TTS/blob/main/qwen_tts/inference/qwen3_tts_model.py). Upstream Qwen's non_streaming_mode flag does not create incremental audio output.
